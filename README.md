# simpleimageshow

사진 하나를 골라서 다른 프로그램 화면 위에 항상 떠 있게 보여주는 작은 프로그램입니다.
테두리 없는 창으로 뜨고, 다른 창을 클릭해도 그 위에 계속 남아 있습니다.

## 설치

Python 3.8 이상이 필요합니다. tkinter가 포함된 Python이어야 합니다(Windows/macOS 공식 설치본에는 기본 포함, Ubuntu는 `sudo apt install python3-tk`).

```
pip install -r requirements.txt
```

## 실행

```
python simpleimageshow.py              # 파일 선택 창이 열림
python simpleimageshow.py 사진.png      # 바로 띄우기
```

Windows에서는 이미지 파일을 `simpleimageshow.py` 위로 끌어다 놓아도 됩니다.

## 조작법

| 입력 | 동작 |
|---|---|
| 왼쪽 드래그 | 창 이동 |
| 마우스 휠 | 확대 / 축소 (커서 위치 기준) |
| Ctrl + 마우스 휠 | 투명도 조절 |
| 오른쪽 클릭 | 메뉴 (다른 사진 열기, 투명도, 항상 위, 위치 잠금, 종료) |
| `+` / `-` | 확대 / 축소 |
| `0` | 원래 크기 |
| `[` / `]` | 투명도 낮추기 / 높이기 |
| `O` | 다른 사진 열기 |
| `T` | 항상 위 켜기 / 끄기 |
| `L` | 위치 잠금 켜기 / 끄기 |
| `Esc` / `Q` | 종료 |

키보드 단축키는 사진을 한 번 클릭해서 창에 포커스를 준 뒤에 동작합니다.

## 제한 사항

- 움직이는 GIF는 첫 프레임만 보입니다.
- 마우스 클릭이 사진을 통과해 아래 프로그램으로 전달되는 기능(click-through)은 없습니다. 아래 창을 조작하려면 사진을 옮기거나 `T`로 항상 위를 끄세요.
- 테두리 없는 창이라 작업 표시줄에 나타나지 않을 수 있습니다. 종료는 `Esc` 또는 오른쪽 클릭 메뉴로 하세요.
